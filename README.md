Goals:
Game structure that promotes a fast flow of events and maximum transition rate to daily users.



Target Audience:
Players interested in a combination of tower defence and strategy genre with customizable map and game options.



Player Interaction:
Mouse clicking is used for interactive actions including placing tiles (towers, etc..),selling towers, pausing the game, changing settings
Mouse hover is used to open the tool box during the game 



Key Features :
Wave Structure of the Game
Health / Gold 
Enemy Types
Tower Types


User Interface / Visuals :
Using free graphical assets and JavaFX for;
Main Menu
Options Screen
Gameplay
Pause Screen
