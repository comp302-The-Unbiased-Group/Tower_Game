# 🏰 KU Tower Defense

KU Tower Defense is a 2D JavaFX-based tower defense game where you must defend your base from waves of incoming enemies by strategically placing towers.
Our goal is to reach an audience of tower defence and strategy game lovers!


---

## 🎮 How to Play

- The enemies follow a **predefined path** on the map.
- You have limited **gold and lives**.
- **Place towers** on buildable tiles (highlighted when you hover).
- Each tower type has unique abilities and range.
- Your goal is to **kill enemies before they reach the end**, or you'll lose lives.

---

## 🧱 Tower Types

| Tower       | Description                             |
|-------------|-----------------------------------------|
| 🏹 Archer    | Fast shooting, single target damage     |
| 🧙 Mage      | Slows down enemies it hits              |
| 💣 Artillery | Deals area-of-effect (AOE) splash damage|

- Towers can be **upgraded** or **sold** during gameplay.
- Each tower has a visual **attack range indicator**.

## 🗺️ Map Editor

The game includes a built-in **Map Editor**, where you can:

- Create custom paths by clicking start and end points
- Draw roads (path tiles) for enemies to follow
- Place decorative and buildable tiles
- Save and load custom maps for replayability

> This makes the game flexible and expandable with **custom levels**.

## 🛠️ Features

- Wave system with increasing difficulty
- Map Editor for custom levels
- Enemy animations (Goblin, Knight, TNT)
- Projectile system (normal, slow effect, AOE damage)
- Gold drop system from defeated enemies
- HUD with live updates for gold, lives, wave counter
- Pause & speed control
- Option settings menu
